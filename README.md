# 🤖 ToolVerse AI

ToolVerse AI is a modern and responsive AI tools directory that helps users discover, compare, and explore popular AI tools across different categories. The project features search, filtering, sorting, dark mode, favorites, and tool comparison in a clean and intuitive interface.

## 🌐 Live Demo

https://ai-tools-encyclopedia.vercel.app/

## ✨ Features

- 🔍 Search AI tools by name
- 📂 Filter tools by category
- 🔄 Sort tools by name or rating
- ❤️ Mark tools as favorites
- 🌙 Dark mode support
- 📱 Fully responsive design
- ⚖️ Compare multiple AI tools
- 💲 Pricing badge for each tool
- ⭐ Tool ratings
- 🔗 Direct links to official websites
- 🍔 Mobile-friendly navigation menu

## 🚀 Getting Started

```bash

```

